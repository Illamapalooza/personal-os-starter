# Taste

How you want things to look and sound. The agent reads `taste.md` before it makes anything other people will see: slides, prototypes, pages, posts.

| File | What's in it |
|---|---|
| `taste.md` | Your design principles: colors, fonts, layout, tone, and what you never want. The agent follows this |
| `references.md` | A log of things you like, with a note on why. The `taste` skill turns these into principles |
| `references/` | Screenshots and images you want to keep |

Add to it with `/taste`: paste a link, drop a screenshot in `references/`, or just describe a look you like.
