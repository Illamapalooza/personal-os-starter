Keep everything in Academics/. Create these files the first time if they don't exist, and ask me for the missing details:
- Academics/Thesis/Progress.md: title, advisor, defense date, a milestone checklist (topic approval, proposal, chapters 1 to 5, final defense, revisions), and a "Where I left off" section
- Academics/Thesis/Feedback.md: advisor feedback, newest first, each item marked open or done
- Academics/Subjects/<Subject>.md: requirements, deadlines, and status for each remaining subject

Make sure the thesis has a row in OS/Context/project-registry.md.

## Status ("thesis status")
1. Read Progress.md, Feedback.md, and Academics/Subjects/.
2. Reply with:
   - Days until the defense, if the date is set
   - Milestones done, and the current one
   - Open advisor feedback, oldest first
   - The next deadline across the thesis and all subjects
   - One next step, small enough to start in 30 minutes

## Log work ("thesis log: ...")
1. Add a line to today's note in Daily/ under "Thesis".
2. Update "Where I left off" in Progress.md. Tick a milestone only if I said it's done.

## Advisor feedback ("feedback: ...")
1. Add each point to the top of Feedback.md as an open item, with today's date.
2. Add anything with a deadline to Tasks.md.

## Subjects ("subject status")
1. Read Academics/Subjects/. List each subject with what's left and the next deadline, most urgent first.

Only use what's in my notes. Never mark something done unless I said so.
