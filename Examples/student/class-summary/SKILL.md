---
name: class-summary
description: Turns a lecture transcript or class slides into a clean lesson note. Use when I share a class recording transcript, lecture notes, or slides, or ask to summarize a class.
---
1. Find the course. Match it to a folder in Academics/Courses/. If it isn't clear, ask. If it's a new course, create Academics/Courses/<Course>/ and add it to OS/Context/project-registry.md with status "ongoing class".
2. Read the source: a transcript (.txt, .vtt, .srt), slides (.pdf, .md), or both. Ignore timestamps, filler words, and tangents. If there are slides, use them for structure and the transcript for explanations.
3. Save Academics/Courses/<Course>/Lessons/YYYY-MM-DD-<topic>.md with:
   - Summary in 3 sentences
   - Key concepts, each with a plain definition
   - One worked example, explained step by step
   - What the instructor emphasized or repeated (likely exam material)
   - Questions to ask in the next class
4. Add any homework, quiz, or exam date to Tasks.md with the due date.
5. Only use what's in the source. Mark anything unclear as [check this].
6. Link the note to earlier lessons in the same course with [[wikilinks]].
7. Confirm in 2 lines: where the note is, and any deadlines you added.
