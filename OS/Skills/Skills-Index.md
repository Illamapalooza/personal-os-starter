# Skills Index

Every skill in `.agents/skills/`. Run one with `/<name>`, or say "use the <name> skill".

| Skill | What it does | Writes to |
|---|---|---|
| `start` | Sets you up, then helps you build your first skill | `OS/Context/`, `Projects/`, `.agents/skills/` |
| `capture` | Parks an idea or task so you can get back to work | `Ideas/`, `Tasks.md` |
| `meeting-notes` | Turns a messy meeting into notes, and updates the project and tasks | `Meetings/`, `Projects/`, `Tasks.md` |
| `switch` | Catches you up on a project | nothing (briefing only) |
| `daily-open` | Plans your day from everything in the system | `Daily/` |
| `daily-close` | Records what got done and what carries over | `Daily/`, `Tasks.md`, `Projects/` |
| `weekly-review` | Looks back on the week and sets next week's focus | `Daily/` |
| `idea-to-mvp` | Turns an idea into a spec and a working prototype | `Builds/`, `Projects/` |
| `reflect` | Turns a correction into a lasting rule | `Meta/Preferences.md` |
| `learn` | Finds patterns in your week and suggests improvements | `Meta/Patterns.md`, `Meta/Optimizations.md` |
