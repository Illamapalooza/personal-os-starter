---
name: daily-close
description: Closes out my day by recording what got done and what carries over. Use when I finish my day or ask to wrap up.
---
1. Read today's note in Daily/ and Tasks.md. Ask me what got done if it isn't clear.
2. Add a "Wrap-up" section to today's note with:
   - What got done
   - What carries over to tomorrow
   - One thing I learned
3. Mark finished items as done in Tasks.md, and update "Where I left off" in any project note I worked on.
4. Keep it short. Don't invent progress.
