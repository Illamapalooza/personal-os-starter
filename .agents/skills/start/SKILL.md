name: start
description: Sets up this personal OS for a new user by asking a few questions, then filling in AGENTS.md and creating project notes. Use when I say start, set me up, get started, or when AGENTS.md still has [placeholders] in it.
---
1. Say in one line that you'll ask a few quick questions to set things up.
2. Ask these one at a time. Wait for each answer before asking the next. Keep each question short and friendly.
   1. What's your name, and what do you do? (student, developer, or something else)
   2. What are you working on right now? Classes, projects, jobs, or side projects. A rough list is fine.
   3. What are your top 3 goals right now?
   4. When do you focus best?
   5. When you're stuck, how do you like things explained?
3. If an answer is vague, accept it. Don't ask follow-ups unless I ask you to.
4. Update AGENTS.md:
   - Replace every [placeholder] and HTML comment in "About me", "My goals right now", and "How I work" with my answers, in my own words, written in first person.
   - Leave "How this vault works" and "Preferences" exactly as they are.
5. For each project or job I named, create Projects/<Project Name>.md with:
   - One line on what it is
   - Status: just started
   - Next step: [add one]
   For each class I named, create the folder Classes/<Course Name>/.
6. If Projects/Example-Project.md still exists and I named at least one project, delete it.
7. Add any deadlines I mentioned to Tasks.md.
8. Show me a short summary of what you set up, then ask: "Want me to plan your day now?" If I say yes, use the daily-open skill.
