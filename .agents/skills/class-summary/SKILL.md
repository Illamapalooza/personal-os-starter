---
name: class-summary
description: Turns a messy class transcript or rough notes into a clean study note. Use when I share a lecture transcript or ask to summarize a class.
---
1. Identify the course. Ask if it isn't clear.
2. Save a note to Classes/<course>/YYYY-MM-DD-<topic>.md with:
   - Summary in 3 sentences
   - Key concepts, each with a plain definition
   - One worked example
   - Questions I should ask my professor
3. Only use what is in the source. Mark anything unclear as [check this].
4. Add [[wikilinks]] to related notes.
5. Add any deadlines or homework to Tasks.md.
